>
> **Фрагмент из [`readme.md`](https://github.com/bol-van/zapret-win-bundle/blob/master/readme.md#%D0%B0%D0%BD%D1%82%D0%B8%D0%B2%D0%B8%D1%80%D1%83%D1%81%D1%8B) репозитория [bol-van/zapret-win-bundle](https://github.com/bol-van/zapret-win-bundle)*
>
> Часть антивирусов относит файлы WinDivert к инструментам повышенного риска или хакерским средствам. В результате файл удаляется и отправляется в карантин; детект обычно называется `WinDivert` либо `Not-a-virus:RiskTool.Multi.WinDivert`.
>
> Добавьте каталог с zapret в исключения антивируса или выключите обнаружение PUA (потенциально нежелательных приложений). Например, в Kaspersky это настройка "Обнаруживать легальные приложения, которые злоумышленники часто используют для нанесения вреда". Если вы уверенно настраиваете исключения, лучше добавить исключение. При отсутствии такого понимания рекомендуется отключить обнаружение PUA.

## ⚙️Использование

1. Сначала включите безопасный DNS (Secure DNS).
    * В Chrome активируйте "Использовать безопасный DNS" и выберите DNS-провайдера, отличного от "Поставщик по умолчанию".
    * В Firefox откройте "DNS через HTTPS", установите режим "Персональный", нажмите "Выбрать провайдера/поставщика" и вручную укажите URL. Например: `https://dns.google/dns-query` (Cloudflare может быть заблокирован).
    * Windows 11 позволяет включить Secure DNS непосредственно в настройках системы — [инструкция](https://remontka.pro/dns-over-https-windows-11/). Для Windows 11 этот вариант рекомендуется.
    * На роутерах Keenetic включите параметр "Транзит запросов". Если его отключить, настройка и работа Secure DNS на компьютере могут быть нарушены.

2. Скачайте zip- или rar-архив с [последнего релиза](https://github.com/peltcashierrepresent/zapret-discord-youtube/releases/latest).

3. Откройте свойства загруженного архива и установите флажок "Разблокировать". Для архивов, открытых через 7-Zip или PeaZip, этот шаг не требуется.

4. Распакуйте архив в каталог, в пути к которому нет кириллицы и специальных символов.

5. Запустите нужный файл.
    * Для поиска подходящей стратегии откройте **`service.bat`** -> `Run Tests` -> `Standard tests` -> `All configs`.
    * Для автоматического запуска выберите **`service.bat`** -> `Install Service` -> *нужную стратегию*.

## ℹ️Краткие описания файлов

- [**`general.bat ...`**](./general.bat) — запуск стратегии вручную.

  Такой запуск удобен для проверки стратегий. Результат зависит от множества условий, поэтому **перебирайте разные варианты (ALT, FAKE и другие), пока не найдёте подходящий именно для вас**.

- [**`service.bat`**](./service.bat) — автозапуск и дополнительные функции:
  - <ins>**`Install Service`** — установить выбранную стратегию в автозапуск через services.msc.</ins>
  - **`Remove Services`** — удалить стратегию и WinDivert из списка служб.
  - **`Check Status`** — посмотреть состояние обхода и служб: стратегии в автозапуске и WinDivert.
  - **`Game Filter`** — включить или выключить режим обхода для игр и других сервисов, использующих UDP и TCP-порты выше 1023.  
  **После изменения режима стратегию необходимо перезапустить.**  
  В скобках отображается текущее состояние: включено или выключено.
  - **`IPSet Filter`** — изменить режим обхода ресурсов из `ipset-all.txt`.  
  Опция полезна при проверке ресурса, который без zapret работает, а с ним — нет.  
  В скобках показывается текущий режим:
    - `none` — ни один IP не проходит проверку
    - `loaded` — IP проверяется на наличие в списке
    - `any` — фильтр применяется к любому IP  
  - **`Auto-Update Check`** — включить или отключить автоматическую проверку обновлений.
  - **`Replace active fakes`** — заменить используемый fake на другой из каталога `bin`.
  - **`Update IPSet List`** — загрузить актуальный `ipset-all.txt` из репозитория.
  - **`Update Hosts File`** — обновить hosts <ins>**для восстановления веб-версии Telegram и подключения к голосовому чату Discord**.</ins>
  - **`Check for Updates`** — вручную проверить наличие обновлений.
  - **`Run Diagnostics`** — найти распространённые причины неисправности zapret.  
  В конце диагностики можно удалить кэш <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=11 /> `Discord`; это иногда помогает при внезапном прекращении работы приложения.
  - **`Run Tests`** — открыть проверку стратегий:
    - `Standard tests` — протестировать сайты из `utils/targets.txt`
    - `DPI checkers` — проверить DPI у разных провайдеров, включая Cloudflare и Amazon


## ☑️Распространенные вопросы и проблемы

### После запуска скрипта `general*` ничего не происходит

При запуске стратегии отдельным bat-файлом, а не через service, должен появиться процесс winws.exe, который можно увидеть на панели задач.  
Если этого не произошло, обратитесь к [#522](https://github.com/peltcashierrepresent/zapret-discord-youtube/issues/522).

### Ни одна стратегия не подходит
- Откройте командную строку с правами администратора.
- Выполните команды по очереди:

    `netsh winsock reset`
  
    `netsh int ip reset all`
  
    `netsh winhttp reset proxy`
  
    `ipconfig /flushdns`

- Перезагрузите компьютер.

### Не работает телеграм (веб версия)

Откройте **`service.bat`** и выберите **`Update hosts file`**. Если файл hosts окажется устаревшим, программа предложит обновить его вручную:  
  - Скопируйте весь текст из открывшегося блокнота.
  - Откройте текстовым редактором с правами администратора файл `hosts` в созданной папке.
  - Вставьте скопированный текст в конец `hosts` или замените аналогичный ранее добавленный фрагмент.
  - Сохраните файл и снова проверьте подключение. При неудаче убедитесь, что изменения действительно записались.

#### Работа не гарантирована. Если этот способ не помог, используйте [Desktop-версию](https://github.com/telegramdesktop/tdesktop/releases) с [локальным прокси](https://github.com/peltcashierrepresent/tg-ws-proxy) либо с любым публичным прокси.

### Обход не работает / перестал работать

> [!IMPORTANT]
> **Стратегии способны со временем переставать работать.**
> Стратегия может какое-то время справляться с обнаружением, а затем перестать работать.
> В репозитории собрано много вариантов обхода. Если ни один не подходит, создайте новый на основе представленного здесь и измените его параметры.
> Описание параметров стратегий находится [здесь](https://github.com/bol-van/zapret/blob/master/docs/readme.md#nfqws).

- Откройте `service.bat` -> `Run Diagnostics` и убедитесь, что ошибок нет.

- Проверьте, присутствует ли адрес ресурса в списках доменов или IP.

- Запустите другие стратегии, включая **`ALT`** и **`FAKE`**.

- Выполните полную переустановку по инструкции ниже.

- Дополнительные сведения: [#765](https://github.com/peltcashierrepresent/zapret-discord-youtube/issues/765).

### Как переустановить/обновить полностью?
- Сохраните добавленные вами ресурсы и другие данные.
- Перезапустите устройство.
- Выполните `service.bat` -> `Remove Services`.
- Затем выберите `service.bat` -> `Run Diagnostics`; исправьте найденные ошибки и в конце ответьте Y.
- Удалите каталог zapret.
- Скачайте свежую версию [`zapret-discord-youtube-...`](https://github.com/peltcashierrepresent/zapret-discord-youtube/releases).
- Нажмите правой кнопкой мыши по архиву и откройте свойства. Если внизу справа есть флажок разблокировки, установите его, нажмите «Применить» и «ОК».
- Распакуйте архив в новую папку в корне диска; в пути не должно быть специальных символов и пробелов.
- Запускайте разные скрипты `general` и проверяйте нужные интернет-ресурсы. Если ресурс не работает, закройте программу через значок замка на панели задач и попробуйте следующую стратегию.
- После выбора рабочего варианта установите его в автозапуск через `service.bat` -> `Install Service` -> нужная стратегия.

### Не работает игра/приложение с включённым запретом

- В `service.bat` проверьте, что `Game Filter` имеет состояние **`disabled`**, а `IPSet Filter` — **`none`**. Иначе фильтрация может затронуть неожиданные ресурсы.

### Античит ругается на WinDivert

- Инструкция доступна здесь: https://github.com/bol-van/zapret-win-bundle/tree/master/windivert-hide

### Требуется цифровая подпись драйвера WinDivert (Windows 7)

- В каталоге [`bin`](./bin) замените `WinDivert.dll` и `WinDivert64.sys` одноимёнными файлами из [zapret-win-bundle/win7](https://github.com/bol-van/zapret-win-bundle/tree/master/win7).

### При удалении с помощью [**`service.bat`**](./service.bat), WinDivert остается в службах

1. Найдите имя службы командой в командной строке Windows (Win+R, `cmd`):

```cmd
driverquery | find "Divert"
```

2. Остановите и удалите найденную службу:

```cmd
sc stop название_из_первого_шага

sc delete название_из_первого_шага
```

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/1384/1384060.png" height=18 /> YouTube

- Проверьте, включён ли [Secure DNS](#%EF%B8%8Fиспользование).
- Отключите блокировщик рекламы: известно, что YouTube начал с ними бороться.
- Если прежняя стратегия перестала работать, попробуйте остальные.
- Дополнительно смотрите [#251](https://github.com/peltcashierrepresent/zapret-discord-youtube/discussions/251).

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=18 /> Discord

- Убедитесь, что настроен [Secure DNS](#%EF%B8%8Fиспользование).
- Сначала желательно определить стратегию, на которой открывается YouTube, и запустить её.
- В `service.bat` перейдите в `Run Diagnostics` и очистите кэш Discord.
- Проверьте приложение Discord и посмотрите, помогла ли очистка кэша.
- Откройте Discord в браузере: https://discord.com/app. Если веб-версия работает, можно пользоваться ей.
- Если Discord не открывается и в браузере, снова проверьте все стратегии. YouTube может работать на одной стратегии, а Discord — нет.
- Дополнительная информация: [#252](https://github.com/peltcashierrepresent/zapret-discord-youtube/discussions/252).

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968804.png" height=18 /> Telegram

- Попробуйте [tg-ws-proxy](https://github.com/peltcashierrepresent/tg-ws-proxy).
- Также можно воспользоваться бесплатными MTProto-прокси из интернета.

### Не работают игры

Игр много, поэтому проверить и исправить каждую из них невозможно.

Начните с универсальной последовательности:
- через `service.bat` обновите ipset и включите `Game Filter`;
- если результата нет, дополнительно включите `ipset any`.

Учитывайте, что режим `ipset any` способен нарушить открытие многих сайтов. Не оставляйте его включённым постоянно: определите IP-адреса, которые использует игра, и добавьте их в `ipset-all.txt`.

Если это не помогло, создайте обсуждение в разделе [Discussions](https://github.com/peltcashierrepresent/zapret-discord-youtube/discussions), а не issue, и дождитесь помощи других игроков.

### Не нашли своей проблемы

- Опишите её [здесь](https://github.com/peltcashierrepresent/zapret-discord-youtube/issues).

## 🗒️Добавление адресов прочих ресурсов

Дополнительные адреса можно вписать в следующие файлы:
- **`list-general-user.txt`** — домены; поддомены учитываются автоматически;
- **`list-exclude-user.txt`** — домены-исключения, например когда сеть уже указана в `ipset-all.txt`, но конкретный домен фильтровать не нужно;
- **`ipset-all.txt`** — IP-адреса и подсети;
- **`ipset-exclude-user.txt`** — IP-адреса и подсети-исключения.
  - Файлы **`*-user.txt`** создаются автоматически при первом запуске `zapret` или `service.bat`.
