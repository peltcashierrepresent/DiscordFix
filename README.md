> [!WARNING]

> ### Реакции антивирусов
>
> WinDivert способен вызвать предупреждение антивируса.  
> Это компонент, который перехватывает и фильтрует сетевой трафик и необходим для работы zapret.
> WinDivert может применяться как легитимными, так и вредоносными программами, однако сам по себе вирусом не является.
>
> **Фрагмент из [`readme.md`](https://github.com/bol-van/zapret-win-bundle/blob/master/readme.md#%D0%B0%D0%BD%D1%82%D0%B8%D0%B2%D0%B8%D1%80%D1%83%D1%81%D1%8B) проекта [bol-van/zapret-win-bundle](https://github.com/bol-van/zapret-win-bundle)*
>
> Часть антивирусов классифицирует файлы WinDivert как инструменты повышенного риска или хакерские утилиты. В результате файл удаляется и отправляется в карантин. Обычно обнаружение называется `WinDivert` или `Not-a-virus:RiskTool.Multi.WinDivert`
>
> Добавьте каталог с zapret в исключения антивируса либо отключите проверку PUA (потенциально нежелательных приложений). Например, в Kaspersky есть настройка "Обнаруживать легальные приложения, которые злоумышленники часто используют для нанесения вреда". Если вы уверенно понимаете настройки исключений, предпочтительнее добавить исключение. Если нет, рекомендуется отключить обнаружение PUA.

## ⚙️ Установка и запуск

1. Включите Secure DNS (безопасный DNS).
    * В Chrome активируйте пункт "Использовать безопасный DNS" и выберите DNS-провайдера, отличного от "Поставщик по умолчанию".
    * В Firefox откройте настройку "DNS через HTTPS", включите режим "Персональный", нажмите "Выбрать провайдера/поставщика" и вручную укажите URL. Например: `https://dns.google/dns-query`, поскольку Cloudflare может быть заблокирован.
    * Windows 11 позволяет включить Secure DNS непосредственно в настройках системы. [Инструкция](https://remontka.pro/dns-over-https-windows-11/). Для Windows 11 этот способ рекомендуется.
    * На роутерах Keenetic включите параметр "Транзит запросов". При его отключении Secure DNS на компьютере может работать некорректно.

2. Загрузите zip- или rar-архив с [последнего релиза](https://github.com/peltcashierrepresent/zapret-discord-youtube/releases/latest).

3. Откройте свойства архива и отметьте "Разблокировать". Пользователям 7-Zip или PeaZip выполнять этот шаг не требуется.

4. Распакуйте архив в каталог, в пути к которому нет кириллицы и специальных символов.

5. Запустите подходящий файл.
    * Для поиска рабочей стратегии откройте **`service.bat`** -> `Run Tests` -> `Standard tests` -> `All configs`.
    * Для добавления стратегии в автозапуск выберите **`service.bat`** -> `Install Service` -> нужная стратегия.

## ℹ️ Назначение файлов и команд

- [**`general.bat ...`**](./general.bat) запускает стратегию вручную.

  Такой запуск удобен для проверки вариантов обхода. Результат зависит от множества условий, поэтому **перебирайте разные стратегии, включая ALT, FAKE и другие, пока не найдёте подходящую для себя**.

- [**`service.bat`**](./service.bat) объединяет установку автозапуска и дополнительные операции:
  - <ins>**`Install Service`** добавляет выбранную стратегию в автозапуск Windows (`services.msc`).</ins>
  - **`Remove Services`** удаляет стратегию и WinDivert из служб.
  - **`Check Status`** показывает состояние обхода и служб, включая стратегию автозапуска и WinDivert.
  - **`Game Filter`** меняет режим обхода для игр и других сервисов, которые используют UDP и TCP-порты выше 1023.  
  После изменения параметра стратегию необходимо перезапустить.  
  В скобках отображается текущее состояние: включено или выключено.
  - **`IPSet Filter`** управляет фильтрацией сервисов из `ipset-all.txt`.  
  Этот режим полезен при поиске причины, по которой ресурс без zapret работает, а с ним нет.  
  В скобках указано состояние:
    - `none` - IP-адреса не проходят проверку
    - `loaded` - проверяется наличие IP в списке
    - `any` - под фильтр попадает любой IP  
  - **`Auto-Update Check`** включает или отключает автоматическую проверку обновлений.
  - **`Replace active fakes`** заменяет используемый fake на другой fake из каталога `bin`.
  - **`Update IPSet List`** загружает актуальный `ipset-all.txt` из репозитория.
  - **`Update Hosts File`** обновляет hosts <ins>для восстановления веб-версии Telegram и подключения к голосовому чату Discord.</ins>
  - **`Check for Updates`** вручную проверяет наличие новой версии.
  - **`Run Diagnostics`** ищет распространённые причины неисправности zapret.  
  В завершение можно очистить кэш <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=11 /> `Discord`; это иногда возвращает работоспособность приложения.
  - **`Run Tests`** запускает проверку стратегий:
    - `Standard tests` - тестирует сайты из `utils/targets.txt`
    - `DPI checkers` - проверяет DPI у разных провайдеров, включая Cloudflare и Amazon

## ☑️ Частые вопросы и неисправности

### После запуска `general*` нет видимого результата

При запуске стратегии отдельным bat-файлом, а не через service, должен запуститься `winws.exe`. Его можно увидеть в панели задач.  
Если процесс не появился, обратитесь к [#522](https://github.com/peltcashierrepresent/zapret-discord-youtube/issues/522).

### Не подходит ни одна стратегия

- Откройте командную строку с правами администратора.
- По очереди выполните команды:

    `netsh winsock reset`
  
    `netsh int ip reset all`
  
    `netsh winhttp reset proxy`
  
    `ipconfig /flushdns`

- Перезагрузите компьютер.

### Не открывается Telegram в браузере

В **`service.bat`** выберите **`Update hosts file`**. Если текущий hosts-файл устарел, программа предложит обновить его вручную:  
  - Скопируйте весь текст из открывшегося Блокнота.
  - Откройте файл `hosts` в созданной папке текстовым редактором, запущенным от имени администратора.
  - Вставьте скопированный текст в конец файла `hosts` или замените аналогичные ранее добавленные строки.
  - Сохраните изменения и снова проверьте подключение. Если результата нет, убедитесь, что файл действительно был сохранён.

#### Работа не гарантируется. При отсутствии результата используйте [Telegram Desktop](https://github.com/telegramdesktop/tdesktop/releases) с [локальным прокси](https://github.com/peltcashierrepresent/tg-ws-proxy) или любым публичным прокси.

### Обход не работает или прекратил работать

> [!IMPORTANT]
> **Стратегии могут терять работоспособность со временем.**
> Вариант, который некоторое время работал, позднее может перестать работать после обнаружения метода обхода.
> В проекте собрано много разных стратегий. Если готовые варианты не подходят, создайте новую на основе одной из них и измените её параметры.
> Описание параметров доступно [здесь](https://github.com/bol-van/zapret/blob/master/docs/readme.md#nfqws).

- В `service.bat` -> `Run Diagnostics` проверьте наличие ошибок.

- Убедитесь, что адрес нужного ресурса присутствует в списках доменов или IP-адресов.

- Проверьте другие варианты, например **`ALT`**, **`FAKE`** и остальные стратегии.

- Выполните полную переустановку по инструкции ниже.

- Дополнительная информация есть в [#765](https://github.com/peltcashierrepresent/zapret-discord-youtube/issues/765).

### Как полностью обновить или переустановить проект?

- Сохраните добавленные вами ресурсы и другие данные.
- Перезапустите устройство.
- Запустите `service.bat` -> `Remove Services`.
- Затем выполните `service.bat` -> `Run Diagnostics`; устраните найденные ошибки и в конце ответьте `Y`.
- Удалите каталог zapret.
- Возьмите свежую версию [со страницы релизов](https://github.com/peltcashierrepresent/zapret-discord-youtube/releases), архив `zapret-discord-youtube-...`.
- Нажмите правой кнопкой по архиву и откройте свойства. Если внизу справа есть пункт разблокировки, отметьте его, нажмите "Применить", затем "ОК".
- Распакуйте файлы в новую папку в корне диска. В пути не должно быть пробелов и специальных символов.
- Запускайте разные скрипты `general`, проверяя доступность интернет-ресурсов. Если текущая стратегия не помогает, закройте программу через значок замочка в панели задач и попробуйте следующую.
- После выбора рабочей стратегии добавьте её в автозапуск через `service.bat` -> `Install Service`.

### Игра или приложение не работает при включённом zapret

- В `service.bat` проверьте, что `Game Filter` имеет состояние **`disabled`**, а `IPSet Filter` - **`none`**. Иначе фильтрация может затронуть неожиданные ресурсы.

### Античит сообщает о WinDivert

- Ознакомьтесь с инструкцией: https://github.com/bol-van/zapret-win-bundle/tree/master/windivert-hide

### Windows 7 требует цифровую подпись драйвера WinDivert

- Замените `WinDivert.dll` и `WinDivert64.sys` в [`bin`](./bin) одноимёнными файлами из [zapret-win-bundle/win7](https://github.com/bol-van/zapret-win-bundle/tree/master/win7).

### После удаления через [**`service.bat`**](./service.bat) WinDivert остаётся среди служб

1. Найдите имя службы в командной строке Windows (`Win+R`, затем `cmd`):

```cmd
driverquery | find "Divert"
```

2. Остановите и удалите найденную службу:

```cmd
sc stop название_из_первого_шага

sc delete название_из_первого_шага
```

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/1384/1384060.png" height=18 /> YouTube

- Проверьте, что настроен [Secure DNS](#%EF%B8%8F-установка-и-запуск).
- Отключите блокировщик рекламы: известно, что YouTube начал активно с ними бороться.
- Если раньше всё работало, попробуйте остальные стратегии.
- См. также [#251](https://github.com/peltcashierrepresent/zapret-discord-youtube/discussions/251).

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=18 /> Discord

- Убедитесь, что включён [Secure DNS](#%EF%B8%8F-установка-и-запуск).
- Сначала определите стратегию, на которой открывается YouTube, и запустите её.
- В `service.bat` откройте `Run Diagnostics` и очистите кэш Discord.
- Проверьте приложение Discord после очистки кэша.
- Откройте Discord в браузере: https://discord.com/app. Если веб-версия работает, временно пользуйтесь ею.
- Если браузер тоже не подключается, последовательно проверьте все стратегии. YouTube и Discord могут работать на разных вариантах.
- Дополнительные сведения: [#252](https://github.com/peltcashierrepresent/zapret-discord-youtube/discussions/252).

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968804.png" height=18 /> Telegram

- Попробуйте [tg-ws-proxy](https://github.com/peltcashierrepresent/tg-ws-proxy).
- Также можно использовать бесплатные MTProto-прокси из интернета.

### Не запускаются игры или нет подключения

Игр много, поэтому проверить и исправить каждую из них отдельно невозможно.

Начните с универсальной последовательности:
- через `service.bat` обновите ipset и включите `Game Filter`;
- если это не помогло, дополнительно включите `ipset any`.

Учтите: режим `ipset any` может нарушить открытие многих сайтов. Не оставляйте его включённым постоянно. Определите все IP-адреса, которые использует игра, и внесите их в `ipset-all.txt`.

Если результата нет, создайте обсуждение в разделе [Discussions](https://github.com/peltcashierrepresent/zapret-discord-youtube/discussions), а не issue, и дождитесь помощи других игроков.

### В списке нет моей проблемы

- Создайте обращение [здесь](https://github.com/peltcashierrepresent/zapret-discord-youtube/issues).

## 🗒️ Добавление адресов других ресурсов

Дополнительные адреса для обхода добавляются в следующие файлы:
- **`list-general-user.txt`** - домены; поддомены учитываются автоматически;
- **`list-exclude-user.txt`** - домены-исключения, например когда IP-сеть есть в `ipset-all.txt`, но конкретный домен из неё фильтровать не нужно;
- **`ipset-all.txt`** - IP-адреса и подсети;
- **`ipset-exclude-user.txt`** - IP-адреса и подсети, которые нужно исключить.
  - Файлы **`*-user.txt`** создаются автоматически при первом запуске `zapret` или `service.bat`.
